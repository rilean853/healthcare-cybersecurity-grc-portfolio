# Penetration Test Findings & Remediation

## Purpose
Demonstrate how technical penetration-test findings are translated into business risk and remediation tracking.

## Fictional Findings
| ID | Finding | Severity | Risk Treatment |
|---|---|---|---|
| PT-01 | Remote service authentication weakness | Critical | Immediate remediation |
| PT-02 | Excessive privileged permissions | High | Reduce privileges and review access |
| PT-03 | Missing security headers | Medium | Harden web configuration |
| PT-04 | Weak password policy on legacy system | High | Enforce stronger controls |
| PT-05 | Informational version disclosure | Low | Reduce unnecessary information exposure |

## GRC Connection
Technical findings should enter the organization's risk/remediation process, receive an owner and deadline, and be verified after remediation.
