# ISO/IEC 27001 Gap Assessment

## Objective
Demonstrate an auditor-style approach to identifying ISMS gaps without claiming certification authority.

## Assessment Themes
- Context and scope
- Information security risk assessment
- Risk treatment
- Security policies
- Asset management
- Access control
- Supplier security
- Incident management
- Business continuity
- Monitoring and measurement
- Continual improvement

## Sample Findings
1. ISMS scope is not formally documented.
2. Risk acceptance criteria are inconsistent.
3. Supplier reviews lack a common evidence standard.
4. Internal audit scheduling is not formalized.
5. Corrective action tracking lacks recurring management review.

## Important
This project is educational. It is not an ISO/IEC 27001 certification audit and should not be represented as one.
