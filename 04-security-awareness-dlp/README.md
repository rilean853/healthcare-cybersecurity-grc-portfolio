# Security Awareness & DLP Scenario

## Security Awareness Program
A 12-month program covering:
- Phishing
- MFA
- Password security
- Social engineering
- PHI handling
- Mobile security
- Remote work
- Ransomware
- Incident reporting
- Insider risk
- Acceptable use
- Data disposal

## DLP Scenario
A workforce member attempts to email a spreadsheet containing patient information to a personal email account.

### Response Workflow
1. Detect the policy violation.
2. Block or quarantine the message where controls permit.
3. Preserve relevant logs.
4. Determine whether data was actually disclosed.
5. Escalate according to incident procedures.
6. Document the event.
7. Identify the root cause.
8. Apply corrective controls.
9. Provide targeted security awareness.
10. Verify remediation.

This scenario is fictional and does not represent an actual incident.
