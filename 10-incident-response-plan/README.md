# Healthcare Incident Response Plan

## Scenario
A workforce account is compromised and suspicious access to a healthcare application is detected.

## Response Lifecycle
### 1. Preparation
Maintain contacts, procedures, logging, backups, and training.

### 2. Detection & Analysis
Validate the alert, preserve evidence, determine affected systems/accounts, and assess scope.

### 3. Containment
Disable or restrict compromised access, isolate affected systems where appropriate, and prevent further unauthorized activity.

### 4. Eradication
Remove malicious persistence, remediate vulnerabilities, reset credentials, and address root causes.

### 5. Recovery
Restore services safely, monitor for recurrence, and validate controls.

### 6. Lessons Learned
Document root cause, control gaps, corrective actions, owners, and deadlines.

## Governance Considerations
Escalation and notification decisions should follow applicable law, contracts, organizational policies, and incident-response procedures. This portfolio scenario is fictional.
