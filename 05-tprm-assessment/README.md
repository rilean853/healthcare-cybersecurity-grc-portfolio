# Healthcare Third-Party Risk Management Assessment

**Vendor:** Fictional HealthCloud EHR

## Objective
Evaluate cybersecurity risk before a healthcare organization uses a vendor that processes sensitive information.

## Assessment Domains
- Security governance
- SOC 2 / independent assurance
- ISO/IEC 27001
- IAM and MFA
- Encryption
- Vulnerability management
- Penetration testing
- Incident response
- Business continuity
- Disaster recovery
- Data retention/deletion
- Subprocessors
- Privacy
- Security insurance

## Decision Framework
This portfolio project demonstrates risk analysis and remediation planning. It does not make a real procurement decision.
