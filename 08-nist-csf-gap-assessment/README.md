# NIST Cybersecurity Framework Gap Assessment

## Framework Areas
- Govern
- Identify
- Protect
- Detect
- Respond
- Recover

## Sample Gap Method
Current State → Target State → Gap → Risk → Recommendation → Owner

## Example
**Current State:** MFA is limited to administrators.

**Target State:** Risk-appropriate MFA coverage for workforce and privileged access.

**Gap:** Workforce accounts remain exposed to password-only compromise.

**Risk:** Stolen credentials could enable unauthorized access.

**Recommendation:** Expand MFA, monitor adoption, and establish exception handling.

This is a fictional assessment for portfolio purposes.
