# Asset Management & Data Classification

## Objective
Create a practical inventory and classification model for a fictional healthcare organization.

## Classification
- Public
- Internal
- Confidential
- Restricted

Restricted data includes sensitive information such as protected health information (PHI), credentials, and highly sensitive business/security information.

## Criticality
- Low
- Medium
- High
- Critical

## Review Questions
- Who owns the asset?
- What data does it process?
- Where is it hosted?
- Who can access it?
- What happens if it becomes unavailable?
- What happens if its data is disclosed or altered?
